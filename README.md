# Triami-website

Nieuwe website voor Triami Triathlonvereniging Deventer: een eigen WordPress block theme plus alle pagina-inhoud, beheerd in git.

Begin bij **PROJECT.md** (stand van zaken, keuzes, werkwijze). Documentatie en rapporten staan in `docs/`.

Snel bouwen:
```
python3 tools/build.py        # dist/triami.zip + dist/triami-paginas-import.xml
python3 tools/blueprint.py    # dist/playground-url.txt (demo in WordPress Playground)
```
