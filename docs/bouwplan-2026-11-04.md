# Bouwplan nieuwe website Triami — woensdag 4 november 2026

Doel van vandaag: een **werkend, bekijkbaar thema-skelet met alle pagina's** van de nieuwe Triami-site, in git, zichtbaar via een WordPress Playground-link. Niet vandaag: hosting, staging, domeinkoppeling, livegang.

Onderliggende rapporten (zelfde map): `inventaris-oude-site.md`, `huisstijl-voorstel.md`, `technische-aanpak.md`, `assets/logo/`.

**Oude site**: WordPress 7.x + Hestia + Elementor 4.3.6, 14 pagina's, 0 nieuwsberichten sinds 2019, homepage is alleen een hero met één knop, geen contactpagina, geen socials gelinkt, Instagram-plugin geladen maar leeg. Placeholders ("Empty", "Titel accordeon"), verouderde jaartallen (tarieven 2025, Start2Tri 2025, teamindeling 2019/2020).

**1-op-1 mee**: bestuur + e-mailadressen + KvK/NTB, trainingsschema (di 19:30 De Scheg, do 20:45 Borgelerbad, wo 19:30 AV Daventria, fietsen informeel), FAQ-regels (opzeggen vóór 30 nov, incasso, NTB-licenties), tarieven (€193 = €144 + €51,50; licentie €35; proeflid €35/10 wk; donateur €25), VCP, clubcompetitie-puntentelling, PDF's (statuten, reglement, privacy).

**Herschrijven**: home, vereniging, start2tri, teamcompetitie, trainers, FAQ, lidmaatschap-kop, clubkleding.
**Vervalt**: nieuwspagina (tenzij gewenst), subpagina reglement, Instagram-plugin, 2019-beeld, Hestia/Elementor.
**Ophalen bij bestuur**: 13 punten (tarieven 2026, teams 2026, trainers/foto's, VCP-mail, zwemjaarschema, Start2Tri-editie, TCC-kalender, kleding/webshop, socials, nieuws-wens, foto's, privacyverklaring, triathlondeventer.nl).

**Huisstijl**: Triami-rood `#ED1E24` (uit vector), zwart `#111111`, lichtrood `#F36B6F`, tint `#FDE8E8`, grijzen; fonts Montserrat (koppen) + Source Sans 3 (body); hartslaglijn als accentmotief. Beste bron: de twee vector-PDF's; echte SVG/transparante PNG's ontbreken (afgeleide SVG's staan klaar).

**Techniek (advies)**: eigen **WordPress block theme** (theme.json, templates, patterns) zonder Elementor; WP 7.1 / PHP 8.3; vandaag tonen via **WordPress Playground** met een blueprint die de thema-zip en een WXR-import laadt vanaf een publieke GitHub-URL; daarna Studio by WordPress.com voor doorontwikkeling; hosting Antagonist Plus+WP met kloon op `test.triami.nl`; plugins minimaal (Fluent Forms, Smash Balloon IG/TikTok, UpdraftPlus, The SEO Framework, Complianz).

## 2. Uitgangspunten voor de bouw

1. Alles als tekstbestanden in één git-repo (`triami-website/`): thema, content, blueprint, documentatie.
2. `PROJECT.md` is het geheugen: huisstijl, sitemap, keuzes, open punten. Elke sessie begint daar.
3. Klein en verifieerbaar: elk blok eindigt met een commit én een zichtbare controle (Playground).
4. Bestuursleden werken straks alleen in de blokeditor; vaste onderdelen (header, footer, trainingsschema, tarievenblok) zijn patterns, zodat niemand de layout sloopt.
5. Geen inhoud verzinnen: onzekere feiten krijgen de markering `[CHECK bestuur]`.
6. Bankrekeningnummer niet op de nieuwe site (fraude-/privacyreden); wel KvK/NTB.

## 4. Tijdblokken vandaag

### Blok 0 — Afstemmen (15 min)
Beslispunten hieronder beantwoorden. Daarna start de bouw zonder verdere vragen; keuzes die open blijven worden als `[CHECK]` in `PROJECT.md` gezet.

### Blok 1 — Fundament (± 60 min)
- Repo-structuur: `theme/triami/`, `content/`, `playground/blueprint.json`, `docs/`, `PROJECT.md`, `.gitignore`.
- `theme.json` v3 met palet, fonts (lokaal gehost woff2), spacing, layout; `style.css`, `functions.php` (minimaal: patterns registreren, fonts), `templates/` (index, front-page, page, single, 404), `parts/` (header, footer), logo's in `assets/`.
- Git init + eerste commit; repo naar GitHub (nodig voor Playground).
- Controle: thema laadt in Playground, header/footer/kleuren zichtbaar.

### Blok 2 — Patterns en pagina's (± 90 min)
- Patterns: hero, trainingsschema, tarieven, bestuurskaart, trainerskaart, teamkaart, FAQ-accordeon (core details-block), CTA-balk, contactblok.
- Alle pagina's uit de sitemap als block-HTML in `content/pages/*.html`, inhoud uit `inventaris-oude-site.md`; placeholders weg, typefouten weg, `[CHECK]`-markeringen waar nodig.
- Script dat uit `content/` een importeerbare WXR maakt (zelfde truc als in juli, nu met block-HTML).
- Commit per pagina-groep.

### Blok 3 — Zichtbaar maken en controleren (± 45 min)
- Thema-zip bouwen, blueprint.json afronden (installTheme + importWxr + homepage instellen + menu), push.
- Playground-link testen in de browser; mobiel en desktop controleren; screenshots in `docs/`.
- Fouten herstellen; commit.

### Blok 4 — Overdracht (± 30 min)
- `docs/beheer-korte-handleiding.md` (voor bestuursleden: tekst wijzigen, nieuws plaatsen, wat niet aankomen).
- `docs/ophaallijst-bestuur.md` (de 13 punten, als afvinklijst).
- `PROJECT.md` bijwerken met stand van zaken en volgende stappen; bouwplan + rapporten in het Claude-project opslaan.

### Buiten vandaag (volgende sessies)
Hosting Antagonist Plus+WP bestellen (jij), kloon `test.triami.nl`, Studio by WordPress.com op je laptop, plugins inrichten, redirects, bestuur laten testen, DNS/SSL, livegang; daarna Hestia/Elementor verwijderen uit de oude installatie.

## 5. Beslispunten (graag per nummer beantwoorden)

1. **Route**: eigen block theme zonder Elementor (advies), of toch Elementor zoals in september besproken? Block theme is lichter, zonder lock-in en volledig in git te bouwen; Elementor is bekender voor het bestuur maar brengt een pagebuilder-afhankelijkheid mee.
2. **GitHub-repo**: mag ik een nieuwe repo `triami-website` aanmaken onder jouw GitHub-account? Voor de Playground-link moet de repo publiek zijn (of de zip op een andere publieke plek staan). Alternatief: privé-repo en vandaag alleen screenshots/zip.
3. **Huisstijl**: akkoord met rood `#ED1E24`, Montserrat + Source Sans 3, en palet strikt rood/zwart/wit (dus zonder het optionele blauw)?
4. **Sitemap**: akkoord met het menu in §3, inclusief nieuwe Contact-pagina? En: Nieuws-sectie opnemen (bestuur plaatst dan zelf berichten) of weglaten?
5. **Socials**: welke accounts bestaan er (Instagram, TikTok, Facebook, Strava-club `triami`)? Dan komen de knoppen/feeds er meteen in; anders alleen Strava en Spond.
6. **Verouderde feiten** (teamindeling, tarieven 2025, Start2Tri 2025): overnemen met `[CHECK bestuur]`-markering (advies, dan is de site compleet) of weglaten tot bevestigd?
7. **Inschrijfformulier**: bestaande Microsoft Forms-embed behouden (nul werk, blijft werken) of later vervangen door Fluent Forms?
8. **Scope**: akkoord dat hosting/staging/livegang vandaag buiten scope zijn en dat Playground de demo-omgeving is?
